PRIVACY POLICY

นโยบายความเป็นส่วนตัว

สำหรับบริการ BWORK Invoice Email ของ บริษัท บิลท์ ฮาร์ท จำกัด ครอบคลุมข้อมูลที่ใช้เตรียมและจัดส่งเอกสารใบกำกับภาษีหรือใบเสร็จรับเงินทางอีเมล

ปรับปรุงร่าง: 5 พฤศจิกายน 2569

บริการส่งอีเมลอยู่ระหว่างเตรียมเปิดใช้งาน โหมด Dry-run บันทึกผลจำลองโดยไม่มีการส่งอีเมลออกไป

1. ข้อมูลที่ใช้และวัตถุประสงค์

ระบบใช้ชื่อและอีเมลผู้รับ รหัสการจอง ข้อมูลผู้เสียภาษีที่ระบุในเอกสาร เลขที่เอกสาร ยอดเงิน และไฟล์ PDF เพื่อเตรียม ตรวจสอบ และจัดส่งเอกสารตามรายการจอง ไม่ขอรหัสผ่าน Gmail ของลูกค้าที่รับเอกสาร

2. การใช้ Gmail API

ผู้ดูแลอนุญาตให้ระบบส่งอีเมลจากบัญชี coworkings.bwork@gmail.com ด้วยสิทธิ์ https://www.googleapis.com/auth/gmail.send เท่านั้น การเชื่อมต่อนี้ไม่ขอสิทธิ์อ่านอีเมล รายชื่อผู้ติดต่อ หรือไฟล์ Google Drive

เมื่อสั่งส่งจริง ระบบส่งที่อยู่อีเมลผู้รับ หัวข้อ เนื้อหา และ PDF แนบให้ Google เพื่อดำเนินการส่ง โดยได้รับรหัสข้อความและผลตอบกลับจาก API เพื่อบันทึกสถานะ ระบบไม่ใช้ข้อมูลที่ได้รับจาก Google API เพื่อโฆษณา ขายข้อมูล หรือฝึกโมเดล AI ทั่วไป

การใช้และส่งต่อข้อมูลที่ได้รับจาก Google API อยู่ภายใต้ Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

3. การจัดเก็บและผู้เข้าถึง

ระบบใช้ Cloudflare Workers, D1 และ R2 ในการประมวลผล จัดเก็บข้อมูลและเอกสารบนระบบคลาวด์ ส่วนระบบพัฒนาอาจใช้ฐานข้อมูลและไฟล์ภายในเครื่อง ไฟล์ PDF ใบกำกับภาษีให้เข้าถึงผ่านกระบวนการตรวจสิทธิ์ของระบบ ไม่ใช้การเปิด bucket เอกสารให้เป็นสาธารณะ

ข้อมูลการเชื่อมต่อบัญชีผู้ส่ง เช่น OAuth Client Secret และ Refresh Token จัดเก็บฝั่งเซิร์ฟเวอร์หรือ Worker Secrets ไม่ใส่ไว้ในหน้าเว็บสาธารณะ เจ้าหน้าที่ที่ได้รับสิทธิ์เข้าถึงข้อมูลตามหน้าที่เพื่อออกเอกสาร จัดส่ง และแก้ไขปัญหา

4. ประวัติการส่งและการเก็บรักษา

ระบบบันทึกอีเมลผู้รับ หัวข้อ เลขอ้างอิงเอกสาร ชื่อและขนาดไฟล์ ผู้ดำเนินการ เวลา สถานะ รหัสข้อความเมื่อมี และข้อมูลประกอบการส่ง เช่น ตัวอย่างเนื้อหาและข้อผิดพลาด เพื่อการตรวจสอบและแก้ปัญหา ประวัติจำลองแยกจากการส่งจริง

ข้อมูลและเอกสารถูกเก็บตามความจำเป็นสำหรับบริการ การตรวจสอบบัญชี การจัดการข้อโต้แย้ง และข้อกำหนดที่เกี่ยวข้อง ระยะเวลาอาจต่างกันตามประเภทข้อมูล ติดต่อบริษัทเพื่อสอบถามระยะเวลาของรายการที่ต้องการ นโยบายนี้ไม่ได้หมายถึงมีการลบข้อมูลอัตโนมัติหลังจำนวนวันที่กำหนด

เมื่อส่งจริง สำเนาอีเมลและไฟล์แนบอาจอยู่ในบัญชีผู้ส่งและผู้รับ การลบข้อมูลในระบบ B-WORK ไม่ได้ลบสำเนาในกล่องจดหมายเหล่านั้นโดยอัตโนมัติ

5. การเปิดเผยข้อมูล

ข้อมูลจะถูกส่งให้ผู้รับที่ระบุและผู้ให้บริการที่จำเป็นต่อการจัดเก็บ ประมวลผล และส่งอีเมล เช่น Google และ Cloudflare รวมถึงการเปิดเผยที่จำเป็นตามข้อกำหนดที่เกี่ยวข้อง บริการคลาวด์อาจประมวลผลข้อมูลในต่างประเทศ จึงควรระบุผู้รับให้ถูกต้องก่อนส่งเอกสาร

6. การแก้ไข ลบข้อมูล และถอนการเชื่อมต่อ

ติดต่อ coworkings.bwork@gmail.com เพื่อขอเข้าถึง แก้ไข หรือลบข้อมูล หรือสอบถามการใช้ข้อมูล บริษัทจะตรวจสอบตัวตนและพิจารณาคำขอตามข้อกำหนดที่เกี่ยวข้อง ข้อมูลบางส่วนอาจต้องเก็บรักษาต่อเพื่อบัญชีหรือการดำเนินการที่ยังไม่สิ้นสุด

ผู้ดูแลบัญชีผู้ส่งสามารถถอนสิทธิ์การเชื่อมต่อได้ที่ หน้าการเชื่อมต่อบัญชี Google ซึ่งจะทำให้การส่งผ่านการเชื่อมต่อนั้นใช้ต่อไม่ได้เมื่อ Google เพิกถอนสิทธิ์แล้ว การถอนสิทธิ์ไม่ย้อนคืนอีเมลที่ส่งไปก่อนหน้า หากต้องการให้ลบข้อมูลการเชื่อมต่อจากระบบ ให้ติดต่อผู้ดูแล B-WORK ด้วย

7. การเปลี่ยนแปลงและช่องทางติดต่อ

บริษัทจะปรับปรุงหน้านี้เมื่อกระบวนการใช้ข้อมูลเปลี่ยนแปลง โดยระบุวันที่ปรับปรุง ติดต่อเรื่องเอกสารและความเป็นส่วนตัวได้ที่ coworkings.bwork@gmail.com
